Purpose: Functions related to chord and onset detection. Strum onsets are marked and segmented into strum and transition groups.
    RMS energy analysis is used to mark strum start onsets. Librosa's rms, chroma and onset detection features are used to analyse the incoming guitar audio from the users microphone
    The microphone input is captured using sounddevice's InputStream in combination with a callback function to enable continous recording by implementing a producer consumer buffer to read and write audio from a shared buffer
    Chord detection is computed by taking the dot product of a template chord vector and the recorded chroma vector. 
    Chord templates are generated by cyclically slicing a template list for minor and major chords. Any minor chord has three notes - Root, Minor Third, Perfect Fifth. Any major chord has three notes - Root, Major Third, Perfect Fifth.

check_chords(detected, prompted)
Compares each detected chord against the chord the user was prompted with, in the order they appeared when printed
    
The function looksahead by one to the next chord in the event that the user makes a mistake allowing them one margin of error.
This helps with the current sensitivity of the onsets that was making the notebook very challenging for a newcomer.
